Guide d'utilisation — CTM-TCY Gestion

🎨 Signification des couleurs

Doré/Or — marque CTM-TCY, ventes, recettes Vert — dépenses, validations, enregistrement, hausse Rouge — suppression, annulation, corbeille, baisse Jaune pâle — alerte « non enregistré »

🔑 Les deux codes

Code d'accès à l'application : CTM2026

Demandé une seule fois à l'ouverture de l'appli (majuscules ou minuscules acceptées). Sans lui, impossible d'entrer dans le logiciel.

Code de modification : International2026

Demandé à chaque action sensible : ajouter/supprimer une ville, modifier ou retirer une vente/dépense, importer une sauvegarde, réinitialiser, ouvrir la Corbeille. Pas demandé pour vendre un ticket, ajouter une dépense, consulter le Bilan ou imprimer.

🎫 Onglet Ventes

Comment enregistrer une vente

1. Cliquez sur la ville (ex. Ouaninou-Abidjan).
2. Entrez le prix du ticket et le nombre de tickets vendus.
3. Choisissez un départ (1er, 2e départ…) si besoin, et l'heure.
4. Cliquez « ➕ Ajouter la vente » : elle apparaît dans la liste du jour.
5. Cliquez « 💾 Enregistrer » puis confirmez « Oui » pour sauvegarder définitivement.

Modifier une vente

Bouton « Modifier » (vert) sur la ligne concernée → code International2026 → changez les valeurs → Valider. La ligne affiche ensuite « ✎ Modifié le… ».

Retirer une vente

Bouton « Annuler » (rouge) → code → justification obligatoire → l'élément part dans la Corbeille (il ne reste plus visible dans les ventes).

⛽ Onglet Dépenses

Même principe : nature de la dépense (Gazoil, Lavage…), montant, justification, puis Ajouter et Enregistrer.

📊 Onglet Bilan

Chiffres du jour, de la semaine, du mois, de 3 mois, 6 mois ou d'un an, avec comparaison à la période précédente (flèche verte ▲ = hausse, rouge ▼ = baisse). Le bouton « Imprimer / PDF » ouvre l'impression : choisissez « Enregistrer au format PDF » pour le télécharger.

🕘 Onglet Historique

Toutes les ventes et dépenses, avec recherche par ville ou nature.

🗑️ Onglet Corbeille

Protégé par le code de modification. Chaque élément retiré peut être « Restauré » (revient dans Ventes/Dépenses, gratuit, sans code) ou « Supprimé définitivement » (irréversible).

⚙️ Onglet Paramètres

Ajouter/supprimer une ville (code requis), exporter une sauvegarde (fichier .json à garder précieusement), importer une sauvegarde, et « Réinitialiser » pour repartir de zéro (code + confirmation requis).

💾 Enregistrement et sécurité des données

Si vous fermez l'appli avec des changements non enregistrés (bandeau jaune « Modifications non enregistrées »), le navigateur vous avertira avant de fermer. Toutes les données restent sur cet appareil : exportez régulièrement une sauvegarde.
